# NetMonitor
Супер-минималистичный монитор интернет-соединения для Windows.
Отображает Ping или статус соединения с интернетом в любом удобном месте экрана.

<img src="https://i.ibb.co/j918fpcJ/Screenshot-2025-12-17-112623.png" alt="Screenshot 2025 12 17 112623" border="0"></a>

## Возможности
- 🟢 **Ping / HTTP Latency**: Автоматическое переключение между ICMP ping и HTTP проверкой (для VPN).
- 🎨 **Оверлей**: Полупрозрачное окно поверх всех окон ("Always on Top").
- 🚀 **Оптимизация**: Минимальное потребление CPU и RAM (использует сокеты и одну сессию).
- 🔧 **Автозапуск**: Включается через контекстное меню (ПКМ).
- 📦 **Автономность**: Устанавливает зависимости самостоятельно при первом запуске (в скрипт-версии).

## Как использовать
1. Скачайте `NetMonitor.exe` из раздела [Releases](https://github.com/confeden/NetMonitor/releases/latest)
2. Поместите его в удобную для вас папку и запустите.
3. Перетащите окошко левой кнопкой мыши в любое место.
4. ПКМ по окошку для доступа к меню (Автозапуск / Прозрачность).
